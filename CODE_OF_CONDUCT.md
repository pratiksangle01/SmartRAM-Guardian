# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep discussion about the work, and do
not harass anyone. Maintainers may edit or remove contributions and block
people who do not follow this.

Report a problem to the maintainers through a private security report on this
repository (Security tab), or by contacting the repository owner on GitHub.
